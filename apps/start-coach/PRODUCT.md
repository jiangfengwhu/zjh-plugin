# 开工搭子 V1.1

任务、卡点和后续动作完全由 AI 处理。不提供内置任务选项、本地动作库、固定卡点类型或直接复用旧建议的捷径。历史只保存用户任务和实际完成步骤，再次开始也重新请求 AI。

主链路：自由输入任务 → AI 给一个可执行动作 → 开工 → 用户点击完成 → 立即展示完成反馈 → 继续请求 AI 下一步，或保存本轮进展。

未连接 AI、超时或生成失败时保留任务，提供重试和连接入口；不生成虚假的兜底建议。用户允许后才发送任务和实际卡点，不提交身份信息。

完成步骤会暂停当前计时并持久化。继续新步骤累积之前已经计入的时间，暂停和生成等待不计入。中途退出后恢复状态，不把计时流逝当作任务完成。

界面文案只服务用户眼前的动作。增长、归因、计时统计口径、开发约束保留在维护文档，不出现在主流程。分享卡以本人确认的完成步骤为依据，任务和昵称默认隐藏，公开文字另行填写。

昵称和身份直接通过 SDK 获取，无独立昵称表单。应用按宿主明暗主题使用语义颜色，正文、状态和操作有明确层级。保留本机事件用于内测，不在用户设置中提供维护者事件导出。
