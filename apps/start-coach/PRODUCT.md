# 开工搭子 V1.2

需要建议时，任务、卡点和后续动作由 AI 处理，不提供内置任务选项、本地动作库或固定卡点类型。用户已知道下一步时，可直接写下自己的动作开始。未完成的同一件事保留身份、实际完成步骤、进展记录和卡点；跨天接续将这些信息交给 AI，不重复从头开始。

主链路：自由输入任务 → AI 给一个可执行动作或用户自己写一步 → 选择尝试时长 → 开工 → 用户确认完成 → 自己继续、请求下一步或保存进展。本轮结束与整件事完成分开；首页优先提供尚未完成的事情。

未连接 AI、超时或生成失败时保留任务，提供重试和连接入口；不生成虚假的兜底建议。用户允许后才发送任务和实际卡点，不提交身份信息。

完成步骤、打开卡点输入时暂停计时并持久化，生成等待不计入。时长结束停在当前动作，用户选择继续、确认完成或结束，不强制跳到总结。继续累积同一件事的实际投入；中途退出后恢复状态，计时流逝不等于完成。

记录页优先展示任务、已完成动作、进展和卡点，分享卡按需展开，以本人确认的步骤为依据，任务和昵称默认隐藏，公开文字另行填写。任务和卡点可点击开始、点击结束语音录入，依赖 SDK 语音能力，隐藏时取消，失败保留文字。界面文案只服务眼前动作；增长和开发约束保留在维护文档。

昵称和身份直接通过 SDK 获取，无独立昵称表单。应用按宿主明暗主题使用语义颜色，正文、状态和操作有明确层级。保留本机事件用于内测，不在用户设置中提供维护者事件导出。
