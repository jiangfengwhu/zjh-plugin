# 开工搭子 V3 · 点火舱 (Ignition Cabin)

全新「晨曦微光 · 单轴心流」设计：暖调羊皮白（`#FAF7F2`）与深空暗色（`#121417`）自适应主题，搭配活力琥珀橙（`#E05A36`）与鼠尾草绿（`#2E6F57`）。遵循宿主深浅主题、系统减少动态效果与安全区域。

声文双栖输入：支持按住流式语音倾诉（实时浮现文字、轻点回放原声）与键盘直接输入，并提供零思考快捷卡点胶囊与三档能量状态选择（10% 躺平破冰 / 50% 稳步推进 / 100% 满电攻坚）。录音保存在应用设备文件目录，文本保存在当前账号存储中；明确点击“帮我拆出第一步”才将文字发送给用户连接的 AI，音频不上传。

微步破冰与连击计时：AI 根据用户当前电量只给一个现在立刻能开始的安全微动作，支持“再切小一半”、“换个切入角度”与“说明具体卡点”。双层流体光环（PulseOrb）承载倒计时进度，时间到了不强制判为完成；用户确认完成后支持顺势连击下一步，或生成高颜值「SPARK RECEIPT · 行动小票」图片分享。
