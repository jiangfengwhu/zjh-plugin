# 开工搭子 V1

首版验证：用户能否从一件具体卡住的工作里做出真实动作，并在另一件任务上主动回来使用。

主链路：说出任务 → 一个小动作 → 默认 5 分钟 → 用户确认第一步／继续推进／尚未开始 → 记住有帮助的办法 → 可选分享。

优先场景为周报、方案和邮件。论文、学习、视频和运动提供本地入口；不以场景数量作为有效性证据。

AI 不作为首次价值的前置条件。默认使用本地动作；用户了解数据处理方式后可启用自己配置的 AI。平台免费 AI 和免配置体验仍需单独验证，不宣称已提供。

不以启动倒计时认定实际行动，不以计时认定专注，不以分享面板打开认定分享完成。只有本人确认的动作进入公开卡片。任务默认隐藏，公开说明由用户另行填写；二维码只携带应用入口、渠道和卡片版本，不含任务或用户身份。账号资料由 SDK 提供，分享卡默认匿名，不另设昵称表单。

仅记录本地事件类型、时间和入口渠道。安装归因、曝光统计、跨端漏斗及集中分析尚未实现；不得把本机事件当作平台增长指标。

接受中断和休息。无排行、连续打卡惩罚或自动发布。三天挑战与组队不进入首版。

内测观察：第一次拿到动作后是否真正做了；卡点修正是否更有帮助；7 天内是否在另一项任务上主动再次使用。比较 AI 建议和本地动作的实际帮助，避免用新鲜感或计时点击代替价值验证。
