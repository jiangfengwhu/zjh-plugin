# 开工搭子 V2

侘寂风格：米纸、墨色、陶土与不规则石头；排版留出呼吸感，主要动作始终明确。遵循宿主深浅主题、系统减少动态效果与安全区域。持续呼吸与声音起伏在 UI 线程运行，仅在页面可见时播放。

主入口仅为声音：按住石头开始、松手结束，轻点回放，按住重新说。不展示转录文字，也没有输入框或文字预览。录音和转录来自同一次 SDK 麦克风采集；录音保存在应用设备文件目录，转录文字保存在当前账号的数据中。明确点击“交给搭子”才将文字发送给用户连接的 AI，音频不上传。模型或权限准备期间松手只完成准备，不自动收音；就绪后再按住录入。隐藏页面或切后台停止录音及回放。

AI 只给一个能立即开始的安全动作，无固定动作库与假兜底。动作页、呼吸计时和完成记录共享石头意象；用户确认完成才留下进展，时间到了不会自动判为完成。卡住时语音说明并暂停计时；结束时可语音留下进度。同一件事跨天保留身份、完成动作与卡点，未配置 AI 或请求失败提供连接与重试。

原始任务和语音转录不在界面、分享卡展示。记录以实际完成动作命名；分享图片仅包含用户确认完成的动作、步骤数和投入时长。替换草稿、历史淘汰和清除记录同时删除不再引用的录音文件；账号切换与页面离开取消异步工作，不写入另一账号。
